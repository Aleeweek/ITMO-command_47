# Тест для самопроверки

## Промпт для составления теста по модулю 3

### Назначение

Промпт предназначен для генерации пяти вопросов рубежного теста по модулю 3 дисциплины «Инфраструктура баз данных для задач ИИ».

### Входные параметры

| Плейсхолдер | Содержание | Значение по умолчанию |
|---|---|---|
| `{question_format}` | Формат вопросов с вариантами ответа | закрытые, один правильный ответ |
| `{difficulty}` | Целевой уровень сложности: базовый, средний или продвинутый | продвинутый |
| `{additional_focus}` | Дополнительный акцент преподавателя; может быть пустым | — |

### Текст промпта

```text
Ты — преподаватель дисциплины «Инфраструктура баз данных для задач ИИ». Составь ровно 5 закрытых вопросов с выбором одного правильного ответа для рубежного теста по модулю 3 «Хранение данных в системах искусственного интеллекта».

Формат вопросов: {question_format}.
Целевой уровень сложности: {difficulty}.
Дополнительный акцент преподавателя: {additional_focus}.

Границы содержания модуля:
1. Требования к хранилищам для ИИ: масштабируемость, доступность, гибкость схемы и выбор платформ.
2. Хранение текстовых корпусов для NLP: организация данных, подготовка к обучению и форматы JSON, BSON, Avro, Parquet.
3. Хранение мультимедийных датасетов: объектные и blob-хранилища, метаданные, дескрипторы, версии данных и воспроизводимость.
4. Интеграция хранилищ с ML-платформами и организация данных для дальнейшей обработки и анализа.
5. Векторные базы данных, эмбеддинги, ANN-поиск и роль хранилища в RAG-системах.

Требования к набору:
- сформулируй один вопрос по каждой из пяти тем;
- вопросы должны проверять обоснованный выбор способа хранения и организацию данных для ИИ-задачи;
- включи не менее трёх прикладных сценариев: для текста, мультимедиа и векторного поиска;
- различай объектное хранилище, базу метаданных и векторный индекс; не приписывай им несвойственные функции;
- в вопросах о RAG отделяй создание эмбеддингов от их хранения, индексации и поиска;
- не используй вопросы за пределами модуля: нормализация реляционных схем, детальная теория NoSQL-моделей и языки SQL-запросов;
- не дублируй проверяемые умения и не объединяй несколько независимых вопросов в один;
- формулировки должны быть однозначными и самодостаточными; у каждого вопроса должен существовать проверяемый ответ;
- для каждого вопроса укажи ровно 4 варианта ответа: А, Б, В, Г; правильным может быть только один вариант;
- все неверные варианты должны быть правдоподобными и относиться к теме вопроса; не используй варианты «всё перечисленное», «ничего из перечисленного» и очевидно абсурдные ответы;
- распределяй правильные ответы между буквами А, Б, В, Г, не используя одну и ту же букву более двух раз.

Верни результат строго в формате:
1. Вопрос: ...
   А. ...
   Б. ...
   В. ...
   Г. ...
   Правильный ответ: [буква]. [полный текст правильного варианта]
   Проверяемая тема: ...

Повтори этот блок ровно пять раз. Не добавляй вступление, критерии оценивания или вопросы по другим модулям.
```

### Самопроверка перед использованием

- В наборе ровно пять вопросов и все пять тем модуля представлены.
- Каждый вопрос соотносится с результатом обучения: сбор, проверка корректности и подготовка данных к обработке и анализу.
- Задания о технологиях оценивают обоснование выбора, а не запоминание торговых названий продуктов.

## Пример результата работы промта.

1.	Какой тип хранилища наиболее подходит для большого набора изображений, аудио- или видеофайлов в ML-проекте?
-	[x] Объектное (blob) хранилище.
-	[ ] Таблица с одним текстовым полем.
-	[ ] Только векторный индекс.
-	[ ] Кэш в оперативной памяти.

2.	Какое преимущество Parquet наиболее важно при аналитическом чтении больших табличных датасетов для обучения модели?
-	[ ] Формат хранит данные только в виде несжатого текста.
-	[x] Формат поддерживает эффективное колоночное чтение и сжатие.
-	[ ] Формат заменяет систему контроля версий датасета.
-	[ ] Формат создаёт эмбеддинги текста автоматически.

3.	Какая информация обязательна для воспроизводимого использования изображения из датасета при обучении модели?
-	[ ] Только имя файла.
-	[ ] Только размер изображения в пикселях.
-	[x] Версия датасета, аннотация, источник данных и контрольная сумма или неизменяемый идентификатор файла.
-	[ ] Название видеокарты, на которой был создан файл.

4.	Что необходимо зафиксировать вместе с запуском обучения в MLflow, чтобы эксперимент можно было воспроизвести?
-	[ ] Только итоговую метрику качества.
-	[ ] Только версию библиотеки PyTorch.
-	[ ] Только ссылку на объектное хранилище.
-	[x] Версию датасета, параметры запуска, версию кода и ссылки на артефакты.

5.	Что должна возвращать векторная база после ANN-поиска для корректной работы RAG-системы?
-	[ ] Только значение косинусного расстояния.
-	[x] Идентификаторы релевантных фрагментов, их векторы или оценки близости и метаданные для извлечения исходного контекста.
-	[ ] Только сгенерированный языковой моделью ответ.
-	[ ] Только исходный PDF-файл без идентификаторов фрагментов.
